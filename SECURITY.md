# Security

Report vulnerabilities privately to contact@smmscout.com or the Telegram
channel https://t.me/smmscout. Do not open public issues for security
vulnerabilities.

Scope: the dataset, the live API (https://smmscout.com/api/panels.json) and the
explorer (https://relaystack.github.io/smmscout-data/). Full policy:
https://smmscout.com/security-policy.txt
