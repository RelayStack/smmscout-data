What is in the SMM panel dataset?

106 SMM panels with Scout Scores on a 125-point scale, measured API latency in milliseconds, live service counts, payment methods, verification status and dated risk flags. The data is published as JSON and CSV, refreshed weekly, and licensed CC BY 4.0. Scores follow the published formula at smmscout.com/methodology.

How the Scout Score works

Longevity 30 (log-scaled) + catalog 25 (log-scaled) + API performance 35 + platform breadth 10 + owner verification 25. Every score is recomputable from the fields in this dataset. Panels under review carry no score; scores are never invented. The dataset includes two panels operated by the publisher (Ezkify, Smmize), disclosed and scored by the same rules.

FAQ

Is the SMM panel dataset free? Yes — JSON and CSV, no API key, CORS open, licensed CC BY 4.0 with attribution to SMMScout.

How fresh is the data? The dataset refreshes automatically every Monday via GitHub Actions; the generated_at field records the pull time.

Why are some panels missing scores? Panels under review are listed with data_quality: "pending" and no score — scores are never invented.
